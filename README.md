# 📦 Inventory Management System

A simple yet effective **Inventory Management System** built to manage products, suppliers, stock levels, and sales efficiently. This project was developed as part of a team assignment to demonstrate CRUD operations and real-world inventory tracking logic.

## 📌 Project Description

- Allows users to manage **products**, **suppliers**, **stock-in/out**, and **sales transactions**.
- Supports core operations: add/edit/delete items, search, and view current inventory.
- Helps small businesses keep track of inventory flow and avoid overstock/understock.

## ⚙️ Technologies Used

- **Python** – Core logic and application
- **SQLite / MySQL** – Backend database (depending on version)
- **Tkinter** or **CLI** – User interface (if applicable)
- **Git** – Version control

## ✨ Features

- 🧾 Product and supplier management
- 📥 Stock-in and 📤 stock-out tracking
- 📊 Inventory reporting (basic level)
- 🔎 Real-time search and filtering
- 💾 Persistent data storage with database
